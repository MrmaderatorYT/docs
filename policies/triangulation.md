# Політика конфіденційності — Триангуляція вишок

Додаток **Триангуляція вишок** (ідентифікатор пакета: `com.ccs.triangulation`).  
Останнє оновлення: 20 листопада 2026.

Цей документ пояснює використання дозволів та обробку даних у додатку **Триангуляція вишок** для Android.

## 1. Хто відповідає за обробку

Володільцем додатка є CyberCraft Studio. Контакти: [cybercraftstudiopro@gmail.com](mailto:cybercraftstudiopro@gmail.com).

## 2. Дозволи на геолокацію та мережу

- **Доступ до геолокації (`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`)**: Вимагається операційною системою Android 10+ для зчитування ідентифікаторів базових станцій стільникового зв'язку з модема та для локального порівняння оцінки триангуляції з GPS.
- **Доступ до інтернету (`INTERNET`)**: Використовується виключно для завантаження тайлів карт OpenStreetMap та отримання координат вишок через API OpenCelliD за наданим користувачем API-ключем.

## 3. Збір та передача даних

- Розробник **не збирає, не зберігає та не передає** вашу геолокацію, історію переміщень чи персональні дані на сервери CyberCraft Studio.
- Ключ OpenCelliD та кеш базових станцій зберігаються виключно локально на пристрої користувача.
- У додатку відсутні реклама та сторонні аналітичні трекери.
