# Політика конфіденційності — Shard

Додаток **Shard** (ідентифікатор пакета: `com.ccs.shard`).  
Останнє оновлення: 26 серпня 2026.

Цей документ пояснює принципи обробки даних у додатку **Shard**. Shard — це локальне середовище для ведення персональної бази знань (PKM), нотаток у форматі Markdown, інтерактивних полотен (Canvas), завдань та редагування документів LaTeX / TeX на вашому пристрої.

Головний принцип Shard — **«Local-First»** та **повна конфіденційність**. Ваші думки, замітки та файли належать виключно вам.

## 1. Хто відповідає за обробку

Володільцем додатка є CyberCraft Studio. У разі виникнення будь-яких запитань щодо цієї політики ви можете зв'язатися з нами електронною поштою: [cybercraftstudiopro@gmail.com](mailto:cybercraftstudiopro@gmail.com).

## 2. Збір та передача даних

- **Повна відсутність збору даних**: Додаток не збирає, не зберігає і не надсилає ваші персональні дані, вміст нотаток, метадані чи файли сховища (Vault) на сервери розробника або третіх сторін.
- **Без реєстрації**: Для використання Shard не потрібен обліковий запис, реєстрація або авторизація.
- **Без трекерів та реклами**: Додаток не містить сторонніх SDK для аналітики (як-от Google Analytics, Firebase чи AppMetrica) та рекламних модулів.

## 3. Відсутність доступу до Інтернету

Додаток Shard **не запитує дозвіл на доступ до Інтернету** (`android.permission.INTERNET`). Додаток спроєктований для 100% автономної роботи (офлайн) і технічно не має можливості передавати будь-яку інформацію через мережу.

## 4. Використання системних дозволів

Додаток запитує мінімально необхідні дозволи для забезпечення роботи локальних функцій:

- **Доступ до пам'яті (`MANAGE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE`)**: Використовується виключно для читання, запису та організації ваших нотаток у стандартній папці `Documents/Shard` (або обраній вами папці на пристрої). Це гарантує, що ваші нотатки зберігаються у вигляді відкритих текстових файлів (`.md`, `.tex`), доступні для відкриття іншими редакторами та не видаляються при випадковому видаленні додатка.
- **Дозвіл на сповіщення (`POST_NOTIFICATIONS`)**: На пристроях з Android 13+ цей дозвіл використовується виключно для показу локальних нагадувань про завдання (To-Do), якщо ви встановили для них термін виконання (`due date`). Сповіщення створюються системним планувальником пристрою локально без залучення серверів push-повідомлень.

## 5. Зберігання, експорт та видалення даних

- **Локальне сховище**: Усі ваші замітки, полотна Canvas, теги, історія версій та налаштування зберігаються виключно на вашому пристрої.
- **Кошик та історія**: Видалені замітки тимчасово переміщуються до локального кошика (Trash) додатка і можуть бути відновлені або остаточно видалені користувачем.
- **Експорт та резервні копії**: Ви можете будь-коли експортувати окремі замітки або все сховище у формати ZIP, Markdown, PDF, HTML чи TXT, а також поділитися ними через стандартне системне меню Android.
- **Повне видалення**: Ви маєте необмежений контроль над своїми файлами та можете видалити додаток разом з усіма даними чи очистити папку `Documents/Shard` за допомогою будь-якого файлового менеджера.
